## Proyectos Destacados

### [TFG] Asistente Virtual Inclusivo con IA Generativa
Desarrollo de un sistema **RAG (Retrieval-Augmented Generation)** para la Facultad de Educación (UCM), diseñado para asistir a estudiantes con discapacidad.
* **Core:** Implementación de modelos de lenguaje locales (**LLMs**) mediante **Ollama** para garantizar la privacidad.
* **Tech Stack:** Python, API REST, LangChain/RAG, Accesibilidad Web.

### [Zephyra] Gestión de Flota Eléctrica Full-Stack
Plataforma integral para la monitorización de vehículos eléctricos utilizando arquitectura **MVC**.
* **Lógica:** Backend robusto con Node.js/Express y persistencia en MySQL con esquemas normalizados.
* **Colaboración:** Desarrollo bajo control de versiones Git con flujo de trabajo profesional.
* **[Ver Repositorio](https://github.com/AdriRedondo/Zephyra)**

### [Ha-Habit!] Tracker de Hábitos Nativo
Aplicación Android para el seguimiento de rutinas diarias centrada en la persistencia de datos y UX móvil.
* **Tech Stack:** Java, Android SDK, SQLite.
* **[Ver Repositorio](https://github.com/AdriRedondo/PAD-2025-26-HaHabit)**
